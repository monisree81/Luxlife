LuxLife is a premium, modern, and highly visual e-commerce web application front-end designed to deliver a luxury shopping and wardrobe-curation experience. The project focuses on fashion aesthetics, clean layouts, smooth user interactions, and styling sets.

1. Key Features

Immersive Hero Experience: A high-impact home page showcasing a full-screen background video, welcoming heading text, and quick-call-to-actions to explore products immediately.

Interactive Catalogue Navigation: A central catalogue hub displaying distinct collections—Women, Men, and Accessories—using clean visual grid layouts and interactive category sliders.

Curated Lookbooks: A specialized "Lookbook" page where users can browse complete outfits/sets (e.g. Linen Jackets, Pleated Pants, Bata Shoes), view itemized breakdowns, see bundled prices, and buy a complete look with one click.

Dynamic Local Cart System: Built-in shopping cart functionality that uses the browser's localStorage to persist items. Users can add products to their cart, verify cart status, and manage selections across page reloads without requiring an external backend database.

Rich Interactions & Scroll Animations: Integration of GSAP (GreenSock Animation Platform) and the browser’s IntersectionObserver API to deliver micro-interactions, subtle fade-ins, and dynamic slide effects as users scroll through items.
